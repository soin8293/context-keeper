# Changelog

## 0.4.1

First standalone release candidate of the Context Keeper Agent Skill and its bundled Python helper.

- Read-only native queries, dry runs and source reconciliation reports.
- Governing prose and corrected table/fence extraction with visible configured limits.
- Explicit source roots, scope-aware identity and history-preserving corrections.
- Multiple scope selection, required policy and linked partial amendments.
- Compact scoped freshness metadata and a separate complete-output cap.
- Reviewed legacy runtime adoption, content-free preservation manifests and shared-runner compatibility.
- Maintenance gating, verified installation receipts, backups and Windows fallback handling.
- Synthetic demonstrations, behavior tests, migration guidance and clean-setup CI.

The release does not introduce semantic truth inference, distributed writers, automatic host injection or a model dependency. Older project runners require a controlled upgrade; installing the skill alone does not migrate them.

- Ingest-first corrections reuse an unambiguous captured replacement, retaining history and policy without adding duplicate current context. Conflicting correction/amendment lineage requires explicit review.
